安裝 Mini Codex
Android：在 Chrome 開啟本網站，使用選單中的「安裝應用程式」或「加到主畫面」。
iPhone／iPad：在 Safari 開啟本網站，點分享，再選「加入主畫面」。
Windows／macOS：在 Edge 或 Chrome 開啟本網站，選網址列的安裝圖示或瀏覽器選單中的「安裝 Mini Codex」。
安裝版會和網站同步更新。App Store、Google Play 與 Microsoft Store 仍需各自的開發者帳號、商店資料及審核。
