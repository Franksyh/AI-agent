INSTALL MINI CODEX

安裝 Mini Codex

Android：在 Chrome 開啟此網站，選單中點「安裝應用程式」或「加到主畫面」。

iPhone／iPad：在 Safari 開啟網站，點分享圖示，再選「加入主畫面」。

Windows／Mac：用 Edge 或 Chrome 開啟網站，選網址列安裝圖示或瀏覽器選單中的「安裝 Mini Codex」。

Windows 本機伴侶版：下載並解壓縮 ZIP，再執行 Start-Mini-Codex.cmd。需要 Python 3.10+ 與已登入的 Codex CLI。

安裝版會隨網站更新。App Store、Google Play 和 Microsoft Store 上架還需要商店開發者帳號、完整上架資料與審核。
